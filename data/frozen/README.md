# Frozen processed iNaturalist data

These ZIPs contain processed historical files used in the selected iNaturalist cohort study. No network access is needed for the offline verification scripts.

- `coarse_start_records.zip`: screening, acquisition hit table, event audits, reconstructed trajectories, and archived outputs.
- `cleaned_analysis_results.zip`: screened-cohort outcome tables and plots.
- `cohort_comparison_results.zip`: initial-versus-screened LP outputs for cross-checking.

The files are *not* a complete copy of the original raw API responses. Do not mistake archived reference taxonomic assignments for independent population ground truth or historical platform consensus. See `docs/data_provenance.md` for acquisition criteria, withdrawn-event handling, reuse qualifications, and limitations.
