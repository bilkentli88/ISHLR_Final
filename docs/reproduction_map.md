# Reproduction map and verification status

This map separates results directly recomputed from saved inputs, independently re-run deterministic benchmarks, archived results checked against reference values, and results for which the original executable workflow is not present in the supplied materials.

| Manuscript analysis | Evidence included | Testable check | Scope |
|---|---|---|---|
| Primary 16-leaf compact/explicit equivalence | Notebook 03, archived CSV/JSON | `scripts/verify_packaged_results.py` or rerun notebook | Saved report verified; notebook can regenerate synthetic data |
| 24-tree projection stress test and historical nonredundancy | Notebook 04, archived CSV/JSON | Same verifier or rerun notebook | Saved report verified; synthetic data generated by code |
| Sample analogue and endpoint-error convergence | Notebook 05, archived CSV/JSON | Same verifier or rerun notebook | Saved report verified; simulation reproducible from notebook |
| Extended depth/horizon/imbalance synthetic experiment | Standalone script, CSV and JSON | `python scripts/benchmark_extended_synthetic.py --out <DIR>` | All 72 configurations and 288 LP comparisons independently re-run |
| Historical-horizon computation time | Two scripts and archived CSV | Run benchmarks; verify saved tables via `verify_horizon_runtime.py` | Structural/LP results reproducible; elapsed seconds hardware-dependent |
| Frozen iNaturalist selection and quality exclusion | Saved screening table and events in `data/frozen/` | `python scripts/reproduce_frozen_inaturalist.py` | 695 initial, 639 screened; screen selection from frozen table, not raw API replay |
| Frozen reconstructed trajectories | Archived event audits | Same command | 3,475 initial and 3,195 screened state cells, no mismatches |
| Γ=12 iNaturalist hierarchy/final/all widths | Frozen trajectories and LP code | Same command | Recomputes archived endpoints to numerical tolerance |
| Reference frequencies versus identified leaf intervals | Frozen trajectories and LP code | `python scripts/verify_reference_frequencies.py` | 21/21 hierarchy, 10/21 final, 7/21 all; 80 violated sibling rows at Γ=12 |
| Full Γ sensitivity path and minimum relaxation | Frozen processed trajectories, LP script, archived sensitivity table | `python scripts/reproduce_sensitivity_path.py` | Independently recomputed Γ=6, 8, 12, 20; agrees at manuscript precision |
| 200-trajectory bootstrap feasibility/width experiment | Frozen trajectories, newly implemented resampling script, bootstrap summaries and 600 resample-level rows | `python scripts/reproduce_bootstrap.py` | Independently reproduced the published numerical bootstrap statistics using 200 complete-trajectory resamples and seed 20261007 |

The summary-level check `python scripts/verify_reported_derived_results.py` verifies that the saved bootstrap and extended benchmark output files contain the stated deterministic results. It does not replace running the generating scripts.

A successful verification command does **not** establish the statistical assumptions of the identification model or provide confidence coverage. In particular, later reference species assignments are neither independently measured population probabilities nor guaranteed to lie inside the sensitivity identified set.

## Verification entry points

```bash
python scripts/verify_repository.py
python scripts/benchmark_extended_synthetic.py --out /tmp/ishlr_extended
python scripts/benchmark_horizon_primary.py
python scripts/benchmark_horizon_scaling.py
python scripts/reproduce_bootstrap.py
```

Notebook reruns may take longer than the packaged-result verification. For the exact archival output versions and LP settings, consult the notebooks and `results/paper/horizon_runtime/README.md`.

The original bootstrap notebook was not supplied, so the standalone script is an independent implementation of the published procedure rather than a verbatim copy of the historical notebook. The published bootstrap feasibility fractions, medians, and day-90 quantiles match this implementation at reported precision.
